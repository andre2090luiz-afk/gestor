# Gestor PrintAR 3D

Sistema de gestão da PrintAR 3D (orçamentos, pedidos, produção, estoque e financeiro).

Os dados ficam no navegador e na nuvem com login — este repositório guarda apenas o código do app.

## Instalar
Abra https://andre2090luiz-afk.github.io/gestor/ no Chrome e clique em **Instalar o app** (no menu do app ou no ícone da barra de endereço). No celular: menu do Chrome → **Adicionar à tela inicial**.

Versão atual: **4.56** — Estoque de produtos em vitrine (clique abre detalhes, parados há +30 dias) + Estoque de material com carretéis (clique abre detalhes, fila precisa, ritmo de uso) + Projetos e Kits redesenhados (ranking, margem colorida, + Pedido/Orçamento) + Clientes (CRM) com segmentos automáticos, chamar de volta e orçamento direto + Agenda redesenhada (arrastar para reagendar, previsão da fila, visão semana) + fundos cinza antigos trocados pelo vidro escuro + fotos nos pedidos agrupados + Pedidos redesenhada (períodos rápidos, separação por mês, chave de pago) + Orçamentos redesenhada (funil, renovar, lembrar cliente, linha do tempo) + janelas, campos e botões no padrão Comando + Pendências redesenhada (filtros, quadro por status, cobrança no WhatsApp) + Central de Comando + números do negócio redesenhados (animações, meta do mês, carretéis) + app instalável que funciona sem internet.
